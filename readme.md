# Fashion Store Admin - SPA Prototype

A minimalist, responsive Single Page Application (SPA) dashboard built for managing fashion store products. It features a clean separation of concerns between backend architecture (Entity, Manager, Controller, API) and frontend UI (Tailwind CSS, state management, toast notifications).
